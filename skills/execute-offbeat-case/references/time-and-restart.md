# 本地时间与续算配方

用于已配置的 ESI OpenFOAM/OFFBEAT 计算。只改请求对应的输入，单位沿用当前 `controlDict.userTime`，缺省按源算例秒制。运行环境由启动器提供；不读取 Time、userTime、timeHandling 或热源 C++ 实现。

## 时间输入一次确定

| 请求 | 输入卡处理 |
|---|---|
| 从零计算 | 独立目标保留源初场，`startFrom startTime`、`startTime 0`；目标不含旧时间目录和旧执行凭据 |
| 固定步长 Δt 到终点 E | `deltaT Δt`、`endTime E`、`stopAt endTime`、`adjustableTimeStep off`；若源含 `adjustableWriteTimeStep`，也设 `false`，避免写出时刻列表改变步长 |
| 每步写出 | `writeControl timeStep`、`writeInterval 1`；只在请求需要每步结果时采用 |
| 指定检查点 | 前段 `endTime` 直接设为交接时刻；公共执行器确认的终态目录作为检查点，不依赖显示位数 |
| ASCII | `writeFormat ascii`；如请求不压缩，`writeCompression off` |
| 从交接时刻 S 续到 E | 独立目标保留完整 S 时刻目录，`startFrom latestTime`、`endTime E`；目标只放该起点与必要输入，不混入更晚时间目录 |

`adjustableWriteTimeStep` 是已有 OFFBEAT 源输入的附加开关，不是 `writeControl` 的取值。固定步长时关闭它即可，保留无关的写出列表。`adjustableTimeStep`、`adjustableWriteTimeStep` 和 `deltaT` 在同一次编辑脚本中处理并回读；不存在的附加开关不凭空添加。时段不能被固定步长整除时按请求明确末步处理，不暗改物理时长。

## 连续路径与分段路径

用户要求 A 连续、B 前后两段时，一次准备三个独立目标和一个任务脚本：A 与 B 前段复用同一源物理输入；两者完成后，B 后段从前段的实际终态目录接入。只有依赖交接数据的复制和续算必须等待，A 与 B 前段可在允许并发内同批执行。不是参数扫描时不为了分支名强制引入优化或采样方法。

1. 源 `0/`、`constant/`、`system/`、根目录模型文件完整复制；沿用材料、气体、燃耗、裂变气体释放等选择器，不因“验证续算”自行启用模型。
2. 复用源配方一次明确的新鲜算例预处理：生成器、网格、OFFBEAT。在独立目标执行，不附加绘图或解析解。源的每个文件不必逐一阅读。
3. B 前段正常完成后，保存整个交接时间目录和运行证据。后段目标复制该时间目录的所有状态文件，包括非 T/D 字段和均匀状态文件；保留网格及相关 `constant/` 数据、模型根文件。不能仅复制温度和位移，不能删除原凭据。
4. 后段复用既有网格，不重新运行可能清理状态或覆盖初场的生成器/清理流程；使用公共执行器启动 `offbeat` 并写新日志。新目标不继承旧 `.mandifuel-execution.json` 作为本次凭据。
5. 从同一批提取结果生成所需终态与交接数据表。保留未请求导出的全部物理状态文件；不额外枚举所有时间×字段×分量，也不为额外边界采样读取网格拓扑。

`fromLatestTime` 是源已经选择的续算/沿用模式；它本身不等于启用了完整燃料演化模型。`none` 也保持原义。报告比较范围以实际沿用的物理选择器为准，不以模型名称自行补开热源、燃耗或气体功能。

## 报错的最短恢复路径

先读该次日志的具体错误及对应输入条目。已正常完成的分支不重跑，已成功提取的数据不丢弃。载荷表 EOF、缺失检查点文件或不支持的输入项分别修复对应输入，保留失败身份、修复输入后建立新尝试继续；默认不设真实启动次数上限；不把报错升级为远程查文档或浏览源码树。无法依据本地材料解决时交付已有分支并说明缺口。
