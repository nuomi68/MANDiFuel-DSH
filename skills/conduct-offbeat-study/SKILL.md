# 按分类执行与交付研究

环境和共享执行器已由启动器提供；直接执行已准备的控制器，不重复检查安装、版本、动态库或源码目录。本技能负责运行与交付；禁止查看或修改底层实现，输入回读、日志、终态和公共契约是工作依据。失败时只修输入或任务调用，可修复输入错误持续修复重算，真实能力阻塞交付明确证据。

## 接收配置是执行前提

先加载 `orchestrate-offbeat-study`，完整内容已注入时复用。确认分类、已保存的点表或原生算法、准备与响应绑定、执行配方、并发及用户明确设置的限制（默认无启动次数上限）；缺项先完成配置，不边逐点试跑边补计划。读取[Study 公共接口](references/study-runner.md)。

研究必须通过共享 Study 管理评价和历史。标准固定点或物化采样使用 Orchestrate 的固定模板；已有 Study 控制器直接复用。完整评价器走 `evaluate=`，自定义执行走 `execute=`，不要另写逐点 shell 调度、去重或状态判断。

## 按类别运行到用户要求的阶段

| 分类 | 必须采用的执行路径 | 本类完成核对 |
|---|---|---|
| `fixed-study` | 完整点表一次交给 `Study.run(points, workers=...)`，再 `Study.collect` | 请求点都有记录；正常、失败、缺失分别统计；只在有效点中按已定规则比较 |
| `sampling-study` | 读取已保存样本表，以 Study 评价，再集中收集 | 不重新抽样；估计器所需块完整；报告有效分母、失败数和设计限制 |
| `adaptive-study` | 原生方法回调通过 Study 评价，或用 `next_points(history)` 分派就绪点 | 每个观测仅更新一次，含最后观测；保留方法状态和真实停止原因；最好点有真实正常评价 |

固定研究遵守[固定设计](references/sweeps-and-candidates.md)；采样研究遵守[概率设计](references/uncertainty-quantification.md)；自适应研究遵守[方法与恢复约定](references/optimization.md)。只读本类所需参考。

使用一个 Python 控制器管理全部评价及算法更新；可能超过前台超时时首次就设置 `run_in_background: true`，再用原生句柄等待，不能先超时再重启。点值变化时复用同一准备与提取路径；纯报告响应不阻塞下一个就绪点。只有新证据改变绑定、方法或修复决策时才返回模型重新规划。

控制器返回宿主原生作业句柄时，用该句柄等到终态。读取已有状态观察进度，不重复启动；不使用 shell `nohup`、`&` 或守护包装。PID 和中间文件不能证明完成。

自适应方法实例与随机状态贯穿研究。单点顺序依赖使用一个 worker，批次方法按其更新边界执行。顺序单目标 Optuna 且接口适用时必须用 `study_runner.run_optuna`，见[持久控制器](references/optimization.md#持久-optuna-控制器)。

## 按失败阶段恢复，不重走整条流程

恢复先沿用原分类，读取共享历史、实际启动记录和方法检查点。已经完成的输入、求解和响应直接复用，中断点和失败点不会自动重跑。

| 当前故障 | 恢复路径 |
|---|---|
| 准备失败 | 修复对应绑定，保留成功回读；确需新尝试时保留旧身份与记录 |
| 求解失败或中断 | 保留输入与日志，修复后建立独立尝试身份和目录重试，直到完成；用户明确限制时才受限 |
| 正常求解后的提取失败 | 只修复提取，使用同一结果根 |
| 报告失败 | 从保留响应修复产物，只检查受影响部分 |

默认不限制真实 OFFBEAT 启动次数；每次启动（含初始化失败、诊断和重试）均记账。只有用户明确设置上限时才按上限停止。`max_evaluations` 是历史条目上限，没有相应用户或方法要求时不设置；失败修复次数不替代请求点数或有效算法观测数。可修复失败按[输入恢复闭环](../execute-offbeat-case/references/input-recovery.md)继续，成功点保持复用。

正常完成可以用 `adopt` 接入；失败运行即使有终态场也不能接入成功。失败场只能作为明确标记的诊断，不进入默认成功统计或优化目标。不能删除凭据或清空历史来触发重跑。

## 集中提取并一次交付

1. 复用已保存 `response`。报告响应通过 `study.collect(extract_reporting)` 一次返回映射并保留 `reporting_response`；成功收集不重复执行，失败收集修复后继续。
2. 新增响应是新的选择，从保留结果集中提取；不把旧映射冒充新选择，也不重新求解。
3. 同一响应映射生成用户要求的表、图和报告。使用已有绘图库或标准库 SVG，不因开放格式图表反复探测转换器或安装额外软件。
4. 按上表核对本类完成条件，分别报告求解、数据和报告状态，以及正常数、失败、缺项和实际启动数。部分结果明确标记部分完成。

涉及物理耦合时读[燃料棒约定](references/fuel-rod-design-studies.md)；只有请求详细标签、符号和并列极值时读[材料区极值](references/repeated-cellzone-extrema.md)。
