# OFFBEAT 工作台与原生 DeepSeek Harness

在项目根目录的 VS Code 终端启动：

```sh
python3 frontend/server.py
```

默认端口 `18765`。VS Code 转发此端口后，打开终端打印的 **OFFBEAT 工作台链接**。链接沿用原生 Harness 的一次性登录机制，登录后自动跳转到 `/workbench/`。需要换端口时使用 `--port`。

启动前会检查端口；如果提示端口占用，先在旧服务终端按 Ctrl+C 退出，或用 `--port 18766` 换端口。关闭终端的挂断信号也会清理原生 DSH 子进程，避免旧实例继续占用端口。

## 界面与任务

前端 agent 的独立角色、技能和操作契约在 [agent/ROLE.md](agent/ROLE.md)、[前端操作技能](agent/skills/operate-workbench-front-end/SKILL.md) 与 [接入契约](agent/CONTRACT.md)。运行时通过私有会话工具 ui_read_skill、ui_inspect、ui_apply、ui_wait_for_render 形成“观察—操作—确认”闭环；主区、右侧、设置及模型的边界由宿主校验，插槽内容由 agent 编排。技能不进入计算助手的技能目录，操作工具也不注册到计算会话。

“结果核查”入口提供可点击的关键物理量，展开后能查看算例、时刻/单位、区域与
运算定义、执行完成性、适用检查、公式/标准、未核验项，以及原文件与 SHA-256。

后台合并重新核查。核查有文件/单元规模和子进程超时限制，不阻塞模型交付或求解。
独立命令与物理边界见 [核查库说明](../lib/mandifuel_verify/README.md)。

UI agent 用 `ui_inspect(target="evidence")` 选择真实记录，给文字/图表/表格附
`evidence:[claimId]`，或用 `type:"evidence", claims:[claimId,...]` 生成相关量表。
数值、状态和来源由程序提供，不允许 agent 覆写。保存场积分、原生回执、解析对照
分别评价；尚未绑定的网格/时间步加密对和独立累计边界通量不被默认视为通过。

右侧直接加载本机安装的 **原生 DeepSeek Harness Web 页面**，包含原生会话列表、输入框、模型选择、工具详情、审批、停止和追问。没有自制聊天输入框、聊天消息渲染或 SDK 替代会话。

嵌入工作台时隐藏 DSH 内部左侧的导航栏，并回收其列宽；聊天输入、模型选择、停止和工具详情继续使用原生界面。新建与切换任务使用工作台顶部入口。直接打开原生 DSH 根页面时仍显示导航栏。

## 项目写入边界

`configs/launcher.env` 可以设置 `MANDIFUEL_PROJECT_ROOT`（默认本仓库）与 `MANDIFUEL_DEFAULT_WORKDIR`（默认项目根，应位于可写目录内）。Web 新会话从默认目录开始，工作台任务仍使用各自的项目内工作区；headless 保留项目内的调用目录，项目外启动时切换到默认目录。当项目的 `runs` 使用外置磁盘时，将 `MANDIFUEL_RUNS_ROOT` 配置为 `realpath runs` 返回的绝对路径，重启工作台后生效。工作台的新任务写入该盘，headless 也支持从这个目录启动。

任务命令、后台进程和 PTY 在 Linux Landlock 中执行，文件工具的创建与编辑也在独立的受限进程中使用原生原子写入和版本检查。项目和已登记 runs 目录以外的文件内容不可创建、覆盖、追加、截断、删除或移动；求解器、Python/OpenFOAM 与外部算例库仍可读取及执行。只授权已配置的实际目录。runs 中指向其他磁盘位置的二级链接保留只读访问。选择 Full access 或请求单次提升不能扩大已登记的写入范围，只读模式仍可收紧权限。任务临时文件与缓存分别放在项目内 `.mandifuel-tmp` 和 `.mandifuel-cache`，`/dev/null` 允许无持久化的重定向。启动时验证实际插件组合，缺失边界插件或 Landlock ABI < 3 就拒绝启动任务工具。

这是任务文件内容的写入限制，不是完整的容器隔离。当前主机的 Landlock ABI 4 不限制 `chmod/chown/utime/xattr` 等元数据操作，也不提供完整的 IPC、设备与既有硬链接隔离；不能把它宣传为严格禁止一切项目外副作用。更强的隔离需要可用的容器或挂载命名空间，本机目前不能创建用户命名空间。DSH 宿主的模型连接、登录和会话存储仍由宿主管理；这些限制不依赖前端页面或主 agent 的提示词。内核行为及限制见 [Linux Landlock 文档](https://docs.kernel.org/userspace-api/landlock.html)。

验证：`python3 -B tests/direct-execution/check_project_boundary.py`；原生文件/命令/终端集成检查为 `tests/direct-execution/check_project_services.mjs`（需启动器准备的 DSH 与 Python 环境）。浏览器验收记录在 `work/project-boundary-qa/`。

页面顶部仅保留任务标题和操作区，不显示独立品牌栏、标题上方的任务类型文字或执行状态标识。“新建任务”为导出右侧的加号图标，全部任务仍可从标题下拉菜单进入。首页不预置基准题或模型，也不显示任务编号。点击“新建任务”会准备独立工作区并切换到原生 DSH 的空白会话；在右侧原生输入框发送物理描述和计算目标后，工作台才登记任务，并使用请求首行作为名称。已有真实任务保留在下拉列表和任务抽屉中。

原生会话选择会同步关联工作台任务。工作区 `AGENTS.md` 仅说明普通计算任务边界，`resources.md` 提供本地资料，不要求计算助手学习前端交付接口。会话若位于工作台准备的工作区，会自动关联；其他原生工作区继续保持原生行为。

DSH 按钮统一控制原生窗口显隐，选中状态跟随窗口实际状态。点击“执行过程”会展开标题下关键进度的历史：摘要和阶段快照来自同一份数据，真实变化时追加，重复工具调用不生成进度行。标题仍显示当前进度。收起时不请求历史，重新展开补齐更新；工具调用和详情继续在原生DSH中查看。进度历史跨重启保留；旧任务没有更早的记录时只保留现有快照并明确提示。

标题下显示当前关键节点和一句简短摘要。原生 DSH 按本地文件变化与显示请求启动独立的“前端操作”子会话；它先加载自己的技能，再按需读取实际页面、数据和能力目录，使用受限工具操作插槽并确认浏览器反馈，没有终端、源码或求解工具。宿主按重要变化合并调用，一次只运行一个任务的前端操作会话。完成消息不投递计算助手收件箱。

网格准备好就会先展示独立的网格预览；没有结果时不显示温度、浓度或时间帧。已有交付每秒检查，结果更新后自动切换到默认结果视图；用户已明确选择其他视图时保留其选择。所有模型来自真实工作区数据，不为显示问题重新求解。

参数抽屉的分组、条目、标签、单位可以由展示子 agent 整组替换。显示设置按当前配置动态生成，可选择正交视角、内部切片、双变量比较、线框、色标、坐标比例以及已有模型视图的切换；同一任务可保留原始网格与有几何依据的对称重建。页面外壳和连接保持稳定，任务展示区可以用 `presentation.ui` 按需组合模型、图表、参数组和操作，不执行任意网页代码。子 agent 的失败只影响展示整理，不改变主任务执行状态；原生输入与结果文件仍可使用。

按需展示采用“组件目录 → 结构化界面 → 校验 → 渲染 → 观察反馈”的方式。用户要求三张线图时，展示 agent 可交付三列网格或标签页；要求 XY 时可发一次性视角指令，或只为当前任务增加相关按钮；要求测点时可添加坐标参数、模型标注和对应的真实保存帧曲线。组件数量、布局、字段和参数由任务配置决定，不预置成三种固定功能。布局与手动参数在任务中保存；新增计算算法仍需真实结果或明确的数据提取，不能由界面生成伪造数值。组件、数据表格式、能力边界及组合示例见 [按需页面交付协议](HANDOFF.md#按需编排展示页面)。

生成式操作组默认收进悬浮“显示设置”，按功能分组并复用同一控件，不在主区域重复生成。只有用户明确要求操作与图表并排时才使用 `placement:"inline"`；设置专用布局不会隐藏主模型或改变模型导出。

单算例在执行中会独立检查真实网格和保存场，不等待展示子任务完成；后续保存帧到达时更新模型，浏览最后一帧时跟随更新，主动选择历史帧时保留所选时间。多参数组必须先登记计划，每完成一组累计交付响应和模型；宿主不根据目录猜测组别。

结果末尾的两个骨架窗口在计算排队、执行和导入期间持续显示。页面收到计算完成、停止或失败的状态后立即收起骨架窗口，展示助手在后台继续提交结果和核对浏览器回执。此后用户主动提出改图等显示请求时，骨架窗口再次出现，在确认、失败或确认超时后收起。任务快照带持久化 `stateVersion`，两路事件与补读都拒收旧版本。页面每 5 秒补读当前任务，并在网络恢复及页面重新可见时立即核对。

当前保存帧的场值全相等时，图例明确显示“当前保存场全域均匀”和真实值，不用人为扩展的色标跨度暗示存在温差。展示观察同时提供真实 min/max/uniform；用户时间单位从 controlDict 核验，`days` 显示为 d，不改动计算数据。

DSH 窗口会检查原生页面、登录状态和客户端握手，加载期间显示进度；登录失效、服务版本不符或连接超时时显示原因，并提供重新连接入口。更新后需要重启 `frontend/server.py` 并打开新打印的工作台链接；仅刷新页面无法更新已运行的 Python / DSH 服务。

模型云图采用蓝—白—红色标，界面继续保持蓝色，PNG 导出使用同一色标。模型区域支持三维旋转、二维平移、缩放、XY/XZ/YZ 正视图、真实单元内部切片、线框、时间播放及 PNG / CSV 导出。双变量并排显示保持相机与时间同步，各用自己的单位和色标；PNG 同时导出两幅图。细长二维模型可选择“展开坐标”，界面与导出会标注坐标缩放。页面下方的“交付文件”区可展开为左侧目录、右侧只读文本框，支持查找、切换和下载输入卡及结果文件。同名文件更新后自动刷新，不重载模型场；二进制或大于1MB的文件提供下载入口。DSH外层不再显示标题或操作栏，窗口显隐统一由顶部DSH按钮控制。手机上原生窗口在模型上方展开，不遮挡顶部开关。

## 扫描、优化与不确定度

左侧按“结果总览 → 参数组 → 模型视图”组织。同一任务包含多次求解时，初次打开默认显示图表；点击图上的点或参数组下拉框可以选组，再切换到模型。参数组抽屉支持搜索、状态过滤和分页，不展开一长串模型窗口。

扫描提供参数响应图和散点图；优化提供评价历史、最好可行值和响应比较，已声明双目标时标记当前非支配候选；不确定度提供直方图、经验累积分布、输入与响应散点图，以及均值、P5/P95。变量、单位、目标方向、约束和图表组合来自当前任务交付，可由DSH替换。

每组独立绑定自己的结果与网格视图、输入参数和响应。失败/未完成组保留状态，不能用0代替缺失响应；选择尚无模型的组会清空上一个模型。切换瞬态参数组优先保持同一物理时间；若该组没有相同保存时刻，显示最近的真实保存时刻，时间单位不同时不擅自换算。

总览只读取标量汇总；模型场按选中视图加载，前后端都有缓存上限。已有单模型任务继续使用原界面。研究导出接口及已有Study history接入见[多参数组交付](STUDY_HANDOFF.md)。

## 连接方式

公开监听由原生 Harness Web 提供，原生 HTML、客户端插件、HTTP API 和 WebSocket 路由均保持原样。工作台通过官方宿主路由扩展点挂载到 `/workbench/`，与原生窗口同源、同端口；不要求再转发一个 Harness 端口。页面鉴权直接调用原生 Connection 的 Host/Origin、令牌和 Cookie 机制。

`native-plugin/` 只做：工作台资源转接、创建原生任务、会话导航桥接、监听原生会话状态与交付终态。它不重写原生输入、消息、队列、停止或模型管理。当前 `scripts/start-dsh.sh web`、现有 Web profile、MANDiFuel Skills 和离线约束继续使用。

任务目录位于 `runs/workbench/<任务ID>/workspace`。会话、历史、恢复和执行生命周期由原生 Harness 管理；Python 服务只登记任务目录和校验交付文件。不会复制模型内部推理到工作台的任务登记文件。

## 输入与结果交付

任务工作区内的 `WORKBENCH.md` 提供现成的 [导出接口](HANDOFF.md)：

```sh
python3 /home/lwz/MANDiFuel-DSH-lwz/frontend/export_case.py \
  --case ./case --output ./delivery/viewer.json --fields T --time latest
```

导出器读取已有结果公共 API，写出 `delivery/viewer.json` 与 `delivery/workbench.json`，不会启动求解器。原生会话本轮完成后，连接插件触发登记与加载。原始边界网格支持任意拓扑；一维对称重建需显式提供形状和真实尺寸。两种显示方式分别标注。原始网格的“内部切片”根据真实单元边与平面的交点构成截面，保留原单元场值，不作平滑插值；非凸单元暂不支持内部切片。原有“剖切”仅隐藏一侧外表面，两种方式可在显示设置中选择。

只准备输入卡时，可在清单只登记 `inputs` / `files`。文件必须位于本任务工作区并在清单登记。导入失败保留上一次成功结果；未变化的交付直接复用。当前单个浏览器数据包上限 64 MB，可按字段、时间段拆分；显示问题不触发重新求解。

二维轴对称 wedge 结果现可按真实截面展开为 270° 旋转体，与原始网格并列切换。显示设置的“标注当前帧全域最大最小值”在真实单元中心添加数值标签，随字段、时间和相机同步，PNG 保留标注；恒定场合并为“最大＝最小”，并列极值注明单元数。旋转体是二维解的几何重建，保留材料间隙；内部切片使用原始网格视图。交付校验会核对实际重建角度、默认视图和极值标注，无法用进度文字代替模型交付。参数与调用见 HANDOFF.md。

展示 agent 还可通过通用 rendering 配置响应用户的 XYZ 显示缩放、命名或自定义色带、色带反转、逐字段色标区间、表面透明度、背景与线框颜色指令。后续指令只需发送变化的属性，之前的设置保留；窗口、图例及 PNG 共用配置，非法或未支持的要求返回明确反馈。

参数窗口支持 agent 定义的任意参数 ID、控件类型、单位、分组和说明，并用 rendering.program 将参数表达式绑定到网格坐标或基础样式。矩形到梯形、剪切等通过数据定义的显示程序完成，无需为每个形状修改前端；参数调整立即更新渲染并保存给下一轮 agent 使用。显示设置与模型参数窗口在右侧原位悬浮，背景不虚化，也不挤压或缩小模型区。显示设置入口位于模型参数右侧；显示设置仅在再次点击入口或点击面板关闭按钮时收起，点击面板外区域、操作模型或使用 DSH 时保持展开。网格开关仅放在显示设置内，同时提供观察方向、复位视角和截图快捷操作，并按实际数据提供极值标注和双变量比较。二维轴对称网格自动提供旋转模型开关，可实时调整 1–360° 旋转角度，取消后显示二维截面；字段、时间帧和原始单元值保持不变。由参数联动控制的选项会禁用对应快捷按钮，自定义参数继续保留。

同一显示程序还可绑定视角与相机、真实保存帧、切片位置、变量比较、逐字段色标，以及点值、文字、线段与箭头标注。点值使用最近原始单元，轴对称重建按径向与轴向距离采样。一次性指令通过 viewState 应用，持续调整通过参数绑定执行；浏览器实际状态和错误通过 viewerState 返回给展示 agent，支持后续相对指令。能力仍受真实数据和渲染引擎限制，未支持的算法会明确反馈。

物理场选择框旁不显示模型和缩放说明。云图极值标注及模型下方最大、最小值默认关闭，可通过“显示设置 → 极值标注”按需开启；保留色标范围和用户指定的测点。提取极值写入结果报告不代表必须在模型区显示极值。

显示设置的观察方向仅提供自动、XY、XZ、YZ，取消独立的“三维”按钮与选项。展示侧可读取已有保存场的类型、分量、单位与运行回执，选择符合任务的应变、位移、应力等图层；字段可声明显示名称，SI 单位与数值仍来自原场。原生物理场下拉框自动列出导出字段，无需重复生成选择参数。一维模型的曲线可直接读取保存场单元中心值，坐标单位继承实际网格元数据，不要求另有 CSV。模型先于可选图表发布，图表配置错误不会阻断有效模型图层。

多工况任务有独立的本地文件监听：稳定的网格、保存场、执行回执、输入卡和结构化报告变化会触发自动登记及展示子 agent。每组以明确的 caseRoot 绑定模型，preview.fields 指定实时展示字段；未完成组可显示保存场并保持运行状态。观察索引独立于主任务交付，不覆盖原始研究表和响应。输入卡覆盖实际各工况，保留失败诊断。

计算与展示隔离：新任务只收到终端计算指令和本地资源，不收到 WORKBENCH/UI 协议。旧的自动生成交付说明保存在任务工作区外的 presentation-legacy，历史会话不改写。展示 worker 由文件事件驱动、拥有独立会话上下文，不挂到计算 agent 的子树；浏览器或展示模型不可用时，计算照常执行。普通 Study 历史可由展示侧 studyMapping 映射，无需主 agent 为 UI 增加步骤。

科学图表由展示 worker 按分析目的编排。默认模型页不再追加“单元场分布”。混合 chart 可叠加折线、散点、阶梯线、柱形和真实区间，配置点形/线型/颜色、对数轴、参考线与容差带；heatmapChart 展示二维采样矩阵并保留缺失格。表格可以直接放主区域，支持格式、单位、搜索、排序、分页和真实最值突出显示。ui.scope=overview 可替换研究总览并保留独立模型页。

数据源可直接读取研究记录，也可把普通终端 JSON 中的 rows/evaluations 与嵌套区间映射成表格，不改写原报告，不要求计算 agent 输出 UI 协议。原始数据、缺失状态和物理单位保持独立于图表样式；不自动平滑、插值或平均重复格。图表 PNG 包含图例与参考线，数据支持 CSV。样例与浏览器验收使用参赛技术报告的真实数据表，见 work/scientific-chart-qa。

图、表、指标和筛选器引用的列会在发布前校验。最佳工况指标取自同一实际可行工况，真实数据尚未产生时保持缺失。数据缓存包含 UI 版本和映射定义，防止更换列配置时复用旧投影。

图表、表格和物理场可通过数据源的 `selection` 共享真实视图、保存时刻与位置；表格的 `filter.context` 可绑定当前视图/时刻。点击曲线点切换对应结构及最近保存帧，时间轴反向更新曲线高亮、剖面与表格。剖面点选会上报 `pickedPoint`，展示 agent 可据此生成坐标参数与点值标注。球对称重建保留原始采样单元，按半径取最近存储值；材料界面用按视图限定的 circle 几何导引表示，不新增物理解。局部修改配色、标题或测点时保留当前选择与未改动组件的交互状态。

纯显示请求通过 Web 请求分流单独交给展示 worker，不进入计算助手的执行队列与模型上下文，也不改变计算状态。真实物理修改、数据提取和混合请求仍由原生计算会话处理；headless 终端执行不加载此分流。展示侧可直接读取带表头的 UTF-8 CSV，保留零、空值、文本标识与原始文件；可选列格式与单位仍由生成的图表/表格声明。细长二维截面优先使用带明确标识的显示比例，径向线图必须依据真实固定截面或明确窗口的采样表，不能连接全部三维单元。

显示请求保留原生聊天记录，通过带来源引用的原生 surface replacement 从计算模型上下文移除；不改写只读的 LLM 请求，也不伪造模型回复。


标题下的流程与展开的执行过程由独立的 `workflow-progress-observer` 维护，读取原生计算事件、计算子任务、真实网格/保存场及求解日志中的时间步；UI agent 不可更新该区域。UI agent 收到当前页面快照并在操作前重新观察，宿主清理单值卡片、完全重复的窗口和空容器。原生模型窗始终可用，从真实网格预览升级为保存物理场，生成布局不能将其隐藏。用户可调的参数输入仍保留实际绑定。
