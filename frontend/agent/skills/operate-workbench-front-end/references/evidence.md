# 可点击的结果核查依据

展示或解释关键工程量时，先 `ui_inspect(target="evidence")` 读取独立程序
生成的真实结论。用返回的 claim ID 关联当前任务；没有记录的结论保持未核验。
`ui_inspect(target="evidence", node="ev-...")` 读取定义、来源、SHA-256、
适用条件、计算式、实际误差、标准及执行完成性。

引用方式：给 text、chart、table 等组件添加 `evidence:["ev-..."]`。
或使用 `{"id":"quantities","type":"evidence","claims":["ev-...","ev-..."]}`
把相关物理量合并成可点击的结果表。值、单位与状态由宿主读取程序记录，
不能由 agent 设置或改写。宿主提供“结果核查”入口，无需重复生成同样的窗口。
引用必须与论述的算例、时刻、区域和运算一致。自动记录覆盖最新稳定保存帧；
不能将该帧的核查推广到整条历史曲线，未有对应记录的历史结论保持未核验。

核查独立于计算 agent，不要求它生成 UI、校核协议或特定交付文件，不发消息
让它等待核查。程序根据稳定输入、保存场、运行回执及日志自动运行，不重算求解器。

- `computed`：依据所列原场和运算得到数值，尚无通过的物理对照。
- `verified`：列出的检查在其范围和容差内通过，不表示整个仿真已验证。
- `failed`：超出该项公开标准，说明具体差异并保留原场和失败记录。
- `not_verified`：证据缺失或不能证明必要条件，不改述为通过。
- `not_applicable`：物理假设不适合该检查，不计作计算失败。
- `stale`：原始文件变化，等待重新核查，旧结果不能当作当前结论。

执行回执和物理检查分别显示。热量积分为实际计算域的量，不自动换算成整棒。
原生有限体积边界功率与保存梯度/矢量的后处理积分分别解释。
Lamé 对照使用真实单元中心和球坐标投影，单元值不冒充面值。
多层铯迁移使用所有区域库存；核芯迁出的量不自动等于最外边界外释量。
日志累计外释量是日志一致性核对，不声称独立通量积分。
缺少明确关联的加密计算对时，网格/时间步收敛保持未核验。
