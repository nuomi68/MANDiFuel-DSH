# 前端 Agent 接入契约

前端提供渲染器、组件目录、插槽和受限操作接口；agent 决定插槽内的组件组合、数据绑定、显示程序与交互。基础设施内置，页面内容通过观察和操作形成。

| 定义 | 位置与实际用途 |
| --- | --- |
| 角色 | [ROLE.md](ROLE.md)，由 native-plugin/frontend-agent.mjs 读取并绑定到私有会话 persona |
| 技能 | [SKILL.md](skills/operate-workbench-front-end/SKILL.md)，通过 ui_read_skill 实际加载；技能资源限于明确登记的文件 |
| 工具 | native-plugin/frontend-tools.mjs，仅在该任务的私有子会话 agent scope 中注册 |
| 版本与插槽 | slot_protocol.py、frontend_session.py，校验修改范围并提交事务 |
| 页面观测 | assets/frontend-state.js、frontend_observation.py，上报真实状态而非仅声明配置成功 |

## 操作闭环

1. `ui_read_skill` 读取技能和本轮需要的参考。
2. `ui_inspect` 读取页面、指定节点、显示设置、模型、数据或能力目录。
3. `ui_apply` 用已观察的版本修改插槽，或操作已有页签、表格和图表。
4. `ui_wait_for_render` 读取实际反馈。新增、修改或显式核验联动时通过 `verifySelection` 让当前浏览器操作一项可见的非默认选择，核对模型切换并还原；检查结果随本轮操作回执返回。

子会话用 `partial` 交接尚缺的组件，宿主将缺口和最近一次写入错误交给下一轮。已提交的面板保留。浏览器确认对应本轮的数据版本，等待期间新增的交付会触发下一轮。连续两次修复仍失败时，工作台在交付文件上方显示原因。

关键结论先 `ui_inspect(target="evidence")`，按 claim ID 查询定义和来源。
组件的 evidence 引用及 evidence 结果表由宿主校验任务归属，数值/状态不可由 agent
写入。原始文件变化使记录过期；核查进程、缓存和技能均独立于计算助手。

main 是左侧组件区，aside 是聊天窗下方组件区，settings 是动态参数定义；model 保留底层渲染设施，通过显示状态、数学表达式和已有场导出操作。支持组件增删、替换、移动、属性修改及受限交互，不接收任意 HTML、JavaScript 或 DOM 选择器。

页面状态包含视口、插槽尺寸、节点可见性、页签、检索/排序/分页、图表范围、当前物理场、相机及实际参数。局部修改保留未改变组件的交互状态；显式 interact 命令用于改变交互状态本身。

每次提交携带版本。配置、用户参数、视图、选择或组件交互已变化时拒绝旧事务；新的用户请求不能被旧操作会话覆盖。每笔最多 24 个操作，每轮最多 8 次修改、24 次工具调用。模型导出先提交，图表随后引用；同一问题最多有限修正两次。

## 与计算隔离

计算 agent 不加载这些角色、技能或工具，headless 计算不依赖前端。文件观察器和 Web 显示请求唤醒独立的展示 owner，完成通知不投递计算助手收件箱。四个工具没有终端、源码读写或求解入口，任务 ID 由宿主绑定，不能跨任务操作。聊天窗、导航、输入和保存场受保护。

页面离线时可保留有效配置，状态保持 pending/offline；没有当前页面的版本确认就不能宣称已显示。前端故障不阻断求解。每次启动操作子会话时读取角色，技能参考按需读取。运行中的子会话沿用本轮角色。
## 页面约束与流程进度

UI agent 的工作提示区分已有页面调整和计算结果整理，携带当前 page 快照，修改前仍须 `ui_inspect(target="page")`。快照包含布局、内容标识、交互状态、视口、窗口遮挡及实际网格/物理场窗口状态。`ui_wait_for_render` 同时校验已有物理场是否真正出现在可见模型窗口。

宿主清理单数值 metric 卡片、完全相同的重复内容及因此产生的空容器；替换窗口应删除旧节点，未选中的不同页签和设置抽屉的临时遮挡不作为删除理由。数值输入参数仍可用于有真实绑定的显示调整。

有真实模型交付时宿主保留原生模型窗口。真实网格生成后独立文件观察器交付网格，保存场出现后升级；生成布局的 replace 或隐藏节点不能使模型窗口消失。UI agent 不写标题流程进度。独立的 `workflow-progress-observer` 读取计算事件、计算子任务谱系、执行回执及求解日志；原生计算助手及其终端工作流不加载 UI 协议。计算子任务与私有 UI 子任务按父会话隔离。

## DSH 应用

ui_calculator 观察并修改 DSH 已生成应用的显示组件。物理绑定由运行层从注册表解析。控件使用原模型参数抽屉，复算结果进入当前模型窗，图表与表格进入工作台的 main、aside 插槽。
