# 五类工程研究示例

## 1. 启动方式

按根目录README配置依赖、DSH及RAG接口后运行：

```bash
python3 examples/run.py --check
python3 examples/run.py D1 --workspace "$HOME/mandifuel-runs/D1"
```

将D1替换为D2、D3、D4或D5即可运行其他任务。提示词只描述研究问题、
物理条件和预期结果。DSH通过技能检索并检查参考算例，再准备输入和计算。
运行入口不预放模板、不指定卡片，也不注入额外提示词。

`--init-only`仅创建含提示词的工作区，不调用DSH或准备物理模型；
`--prepare-only`是其兼容别名。`--check`只校验随包文件完整性。
任务执行后，最终回复、状态和计算产物留在工作区。

## 2. D1：水冷通道瞬态响应

研究升功率过程中的壁温、冷却剂温度及轴向温差。完成一次14400 s
瞬态求解，再对已有结果追问分析或绘图。该案例展示单次求解与多轮后处理。

## 3. D2：TRISO涂层参数扫描

保持完整五层颗粒和初始外半径，以3种Buffer厚度与3种SiC厚度形成9个
组合。每组独立计算至2.5e7 s，比较颗粒气体内压和核芯最高温度，
绘制组合热图及温度—内压权衡图。最多两个组合同时运行。

## 4. D3：轴向功率形状优化

保持平均线功率历史，用两个形状参数调节整根燃料段的轴向功率分布。
采用Optuna TPE搜索，以3.15e7 s的燃料最高温度为目标，预算12次候选求解。
检查节点功率积分归一化，并展示搜索轨迹及最优已计算形状。
首轮完成后，可在同一个DSH会话中继续输入`D3/followup.txt`，在已识别的
低温区域开展8点局部搜索，形成12点范围探索与8点局部加密的多轮研究。
运行入口只执行首轮提示词；追问由使用者在原会话提交。

## 5. D4：氧化温度不确定性传播

对截断正态界面温度进行8点一维拉丁超立方抽样，每个温度独立求解
3650 d的氧化层生长。比较终点样本统计量、2微米阈值和生长曲线。
8点结果属于有限样本展示，不作为高精度概率或可靠度估计。

## 6. D5：铯扩散系数反演

以球形UO2核芯在50000 s释放50%的初始铯为目标，对常扩散系数进行
区间二分反演，最多9次候选求解。响应来自核芯体积分库存减少量，
并用球形扩散解析解比较量级；达到误差条件即可提前停止。

## 7. 依赖与计数

需要DSH、已编译的OFFBEAT/OpenFOAM、对应参考算例库、RAG接口及
`requirements-examples.txt`中的科学计算库。启动方法与版本要求见根目录README。
每次实际启动OFFBEAT才计为一次物理求解。保存时间步、重复参数的缓存命中、
响应提取及绘图均不增加求解次数。DSH退出成功仍需结合原生求解日志和结果
检查任务是否完成；各项预算表示请求范围，不代表本包预存了这些计算结果。
