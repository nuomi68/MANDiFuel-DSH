# 保存结果的独立核查

该库只读取已有 OFFBEAT 输入、网格、场、执行回执及原生日志。
不调用 LLM、前端或求解器，不修改算例。Python 3.12 和仓库已有解析器即可运行。

```sh
python3 scripts/verify-results.py --case path/to/case --output path/to/evidence.json
python3 scripts/verify-results.py --case path/to/case --check cesium --time latest
```

默认报告到标准输出，`--output` 必须在被核查的算例目录之外。
输入和场仅支持可解析的 ASCII；不会执行 OpenFOAM 指令、展开宏、猜测缺失量或启动计算。
每个来源记录工作区相对路径、文件角色、大小及 SHA-256。读取时检查文件身份；
读到的内容在整次核查结束前发生变化时，整份报告标为 stale。

## 覆盖范围

| 检查 | 输入与方法 | 内置比较标准 |
|---|---|---|
| 执行完成性 | 原生回执、退出码、结束标记、精确匹配日志时刻、controlDict.endTime 与保存终点 | 所有证据一致才通过 |
| 稳态导热 | 明确的 solidConduction/steadyState；原场 Σ QV，与边界 Σ q·S 对照 | 归一化残差 ≤ 1% |
| 原生边界热流 | 精确匹配时刻的 Boundary power summary 与独立原场 Σ QV | 归一化残差 ≤ 1% |
| 球壳 Lamé | 原点球心、固定网格、单一均匀常物性线弹性、纯压力、无热应变；D 和 sigma 在真实单元中心作球坐标投影 | 相对解析剖面尺度的最大误差 ≤ 2%，另查应力球对称性 |
| 铯库存/外释 | 全计算域 Σ CsV，与同一时刻原生日志的 N0、累计外释、剩余及分数逐项核对 | 相对初始库存/分数差 ≤ 0.005 |
| 初始铯库存 | 真实初值场或明确覆盖每个材料区的初始浓度与静态网格 | 与日志 N0 相差 ≤ 0.5% |
| 裸球扩散解析 | 无内孔、均匀初值、零生成源、全历程常 D、外表面 Cs=0、明确时间单位 | 释放分数绝对差 ≤ 0.005 |

这些是透明的内置演示核查标准，不是核安全验收标准，也不构成整体仿真有效性认证。
量纲、符号、区域、计算域尺度和样本位置均保留。单元中心值不是边界面值。
热流矢量/梯度的后处理积分与原生有限体积守恒热流不是同一个离散量，分别报告，
不会因原生摘要吻合就删掉后处理积分不吻合的记录。

铯外释核对使用整个计算域，不能将核芯迁移至涂层的量当作对外释放。
日志累计外释量不是本库独立积分的累计边界通量，因此报告仅声称原场与日志的一致性。
非零源项若没有完整累计源证据，不做零源平衡。未明确提供的初始浓度不补零。
移动网格的初始库存和恒定球域解析对照暂不自动核验。
缺少明确的同物理加密计算对时，离散误差/收敛性保持 not_verified。

## 数据契约与扩展

`verify_case(case, workspace=..., time='latest', checks=None)` 返回
`mandifuel.evidence/v1`：`claims`（数值、定义、来源、相关检查）、`checks`
（范围、假设、计算式、实际指标、标准及状态）、`sources`、内容版本与生成时间。
claim ID 在同一任务内按相对算例路径和响应定义保持稳定；读取接口始终绑定任务。
当前文件的 SHA-256 只证明本次核查读取的版本；历史回执未保存可验证的运行时
输入指纹时，“当前输入与执行时版本的绑定”保持未核验，不追溯补造历史证明。
`computed` 表示从原场计算，`verified` 表示指定检查通过；`failed`、
`not_verified`、`not_applicable`、`stale` 分别保留，不折算成无依据的总置信分。

扩展检查在 `checks.CHECKS` 注册确定性程序，必须声明适用条件、实际数据来源、
公式、比较标准及不支持项。执行完成性与数值检查始终分开。

公式参考：球壳采用三维弹性 Lamé 解；球扩散采用均匀初值吸收边界的体积分级数解。
源码中直接给出实现，测试包含独立边界条件、解析恒等式和受控扰动；
真实热流、球壳和铯迁移案例的只读核查记录位于本机 `work/evidence-qa/`。
