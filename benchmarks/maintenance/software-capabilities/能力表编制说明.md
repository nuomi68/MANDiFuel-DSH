## 对现有问题的处理

- `none`不是通用关闭值。当前力学固定入口是`mechanicsSolver constant`，含义是沿用状态，不是清零位移。
- `solidConduction`实际评价`fuelRodGap`时，`gapGas none`会缺少所需气体导热物性。温度方程固定、未评价该边界时，不据此强制启用气体。固定热阻`resistiveGap`的源组合另有自身适用范围。
- `constantLhgr`使用标量，`timeDependentLhgr`使用配对时间/载荷列表。源输入已满足请求时保留，尤其不随意截断较晚的时间末点。相等末点曾失败，但不将它当作所有模型和步长必失败的硬规则。
- 公共`list_scopes`确实存在，空`defaultFaces`造成的是解析限制。之前中文轨迹把一次绕过查询误写为“移除不存在的接口”，已更正派生翻译；原始轨迹和数值证据未变，见[勘误核对](trajectory-correction.json)。

## 使用方式与边界

从能力表入口按相关项一次查询，避免把整张表加入每次任务的上下文：

```bash
python3 "$MANDIFUEL_PLUGIN_ROOT/skills/prepare-offbeat-case/scripts/software_capabilities.py" show mechanicsSolver gapGas time
python3 "$MANDIFUEL_PLUGIN_ROOT/skills/prepare-offbeat-case/scripts/software_capabilities.py" check --case case --source source-case
```

也可在已有批量准备脚本中调用`query([...])`及`check_case(case, source=source)`，合并到一次工具动作。检查器只调用禁用函数入口和动态库的原生字典工具，不修改输入，不启动OFFBEAT。Prepare要求涉及模型选择器、热边界或时间载荷的改卡保存该检查；同输入记录复用，Execute不重复检查。

检查覆盖已知非法力学选择器、被激活的热边界依赖、字面载荷表长度及时间覆盖风险等。它不构成完整输入模式、注册表穷举或物理精度认证，也不是无法绕过的运行时总闸。初始边界按`0/T`检查；包含文件、宏、重启状态和全部模型参数不在其完整覆盖内。未知模型只标记未核实，不因未收录阻断新任务。运行反馈修复和默认不限求解次数的既有规则继续适用。
