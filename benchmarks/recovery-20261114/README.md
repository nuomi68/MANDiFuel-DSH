# 默认不限次数的输入恢复机制

已更新开发规范、运行身份和相关 Skill：默认不限制真实 OFFBEAT 启动次数，可修复输入错误要依据运行反馈修改后继续求解。失败证据保留，新尝试用独立目录，成功结果复用；仅准备/仅提取任务和用户明确设置的限制继续遵守。

公共执行器返回有界原生错误摘要及合法类型信息；同一目录仍幂等，修复后用新身份运行。默认记账包装器允许持续重试，不添加次数硬闸。开发原则要求按接口和依赖复用能力，未覆盖组合可以通过一般输入工作流和运行反馈推进。
