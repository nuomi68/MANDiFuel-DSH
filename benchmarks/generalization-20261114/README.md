# 当前 Skill 的跨任务配对试验

本轮选择 C02 球壳压力、C08 绝热双区域瞬态热能、F01 三种中心孔径。三题均未参与 C06 固化，也不命中 Cs 常扩散契约。当前产品全程冻结，两组使用同题面、源输入、模型和预算，任务工具离线。

C02、F01 成功配对的 Skill totalTokens 分别减少 81.2%、38.4%。C08 完成范围不同，不计算有效加速。每题仅一次配对，不据此推断稳定性能或总体优越性。

实际启动共 16 次，其中正常 9 次、失败 7 次，全部计入各题预算。组织者只做读取、原生几何后处理与积分核对，没有补跑 OFFBEAT。95 项完整性检查通过，11 个原生关键场的快照哈希一致，C08 裸组 30 项能量表数据与独立积分一致；保留 523 行中文工具事件及原始轨迹。

C08 失败暴露通用缺口：关闭力学要用本机支持的选择器，`fuelRodGap` 依赖有效气体模型。C02 的载荷表末点、F01 的旧采样函数语法也各自消耗了两组启动。后续适合固化这些有限输入契约，另建版本复测；本轮未改 Skill。

核对代码保留在 `../candidate-pairs/generalization_checks.py`；列名识别对单位后缀、单 r/双 rr 写法做过修正，原始自动结果及修正哈希均随运行保存，物理要求不变。详情见报告。
